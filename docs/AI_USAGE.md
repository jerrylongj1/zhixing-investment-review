# AI 使用与验证记录

日期：2026-10-18。本文区分开发阶段 AI 与产品运行时 AI，避免把程序规则冒充模型能力。

## 使用了什么

- 开发助手：本会话中的 Codex。参与需求澄清、设计规格、实施计划、Python/React 实现、测试编写、浏览器验收、文档与交付打包。
- 独立代码审查：通过 Codex 子代理进行只读审查，检查时点泄漏、数据隔离、金融计算、外部响应、前端时间精度；反馈由实施代理复现并修复。
- 产品运行时：可配置支持 Chat Completions 严格 JSON Schema 的 HTTPS 模型服务，配置项见 README。没有预置真实密钥；本次未进行真实模型端到端调用。
- 规则辅助：确定性 Python 逻辑生成交易事实、缺口提示和通用过程检查。UI 和导出均标记 rules，不把它标为 AI 输出。
- 未使用 AI 图像生成或虚构真实金融数据。样例交易、经营事件、价格及同期理由是明确标注的构造内容。

## AI 与程序职责

程序负责时区和可得时间过滤、逐笔决策证据白名单、Decimal/FIFO 计算、确定性事实条目、结构/引用校验和持久化。AI 只在明确的证据边界内提出条件性归因假设、偏差线索、不确定性和过程改进。提示中将证据原文定义为不可信数据，而不是指令。

模型接口与结构化输出的实现依据 [官方结构化输出文档](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat)。不固定某个未经用户授权的付费模型，不替用户创建密钥。

## 实际纠正过的结果与实现

| 问题 | 验证与修正 |
|---|---|
| 单一观察截止点可能把较晚信息用于较早交易 | 增加逐笔 `knowledge_by_decision`，限制每条结论在涉及的每个决策时点均可知。批量时点回归测试先失败后通过。 |
| 最初的建议拦截只覆盖特定措辞 | 审查复现“请买入…并持有，下周会上涨”能绕过校验；解释分区扩展保守的操作词及预测词拦截，增加中英文回归。仍不宣称词法校验能够证明语义安全。 |
| 合法 JSON 可能不是合法报告 | 审查发现 `[]`、`choices: []` 可导致非受控错误；增加信封和内容结构校验，统一转为 ReviewError，不保存正常报告。 |
| 提供方返回坏结构或非法数值 | 审查复现列表信封、`close_price="garbage"`；校验字典/列表并处理 Decimal InvalidOperation，转换为 ProviderError；API 保存失败状态，不填充演示数据。 |
| 请求支持 100 笔，但报告原限制 30 项 | 增加确定性报告容量，实测 100 笔无理由交易可生成事实与缺口项。 |
| “回到此刻”截断成交秒数 | 10:15:30 曾被还原为 10:15:00；保留秒数，使用 step=1 和统一时区拼接。旧实现下测试失败，修复后通过。 |
| 保守拦截误伤合法交易 ID | 审查发现 `buy-1` 出现在缺口文本会被误判；ID 移至结构化 decision_ids，确定性提示不拼接元数据。buy-1、sell-1、中文 ID 回归通过。 |
| 将行情日期当作历史公开时间的风险 | 核实扶摇文档：date_ms 和 data.timestamp 不能证明单根日线历史首次公开时间。适配器明确保存 available_at=null、quality=missing，而不是自造 15:00 或 15:05。 |
| 本地构建工具不可直接执行 / esbuild 被拦截 | 使用已提供的 Node 运行时，明确只允许 esbuild 安装脚本，完成类型检查及生产构建。未放开全部依赖脚本。 |

## 验证证据与限制

自动化测试用真实领域函数、临时 SQLite 和 FastAPI TestClient 运行；外部接口用 httpx MockTransport 构造超时、非法响应和成功返回，测试不会发送真实持仓或密钥。浏览器实际操作了样例、后续切换、引用抽屉、报告、学习清单、CSV 粘贴预览/导入和重启后的数据保留。

没有真实模型调用、真实扶摇授权调用或 iFinD 连接验证；不能据此报告模型事实准确率或真实行情完整性。AI 修正和程序测试由代理执行，用户尚未提供独立人工审计结果。结构/引用校验只证明形式和允许的来源关联，不能证明推理因果、来源真实或文本完全无风险。报告中明确保留该限制。

公网联调额外发现：TLS 隧道终止处与后端 URL 的协议不同，使正确的浏览器 Origin 被拒绝为 403。增加显式 PUBLIC_ORIGIN 配置，仅允许该规范来源写入；保留恶意来源拒绝测试，不以放开所有 Origin 解决。回归先失败后通过。
